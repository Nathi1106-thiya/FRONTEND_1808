HTML (HyperText Markup Language) uses tags to structure a webpage. Tags usually look like content. Here are the most important HTML tags and what they do: 1. Basic document structure Tag What it does DOCTYPE html Tells the browser this is HTML5 html Root of the HTML document head Contains page information/settings title Sets the browser tab title body Contains everything visible on the page 2. Text tags Tag What it does h1 – h6 Headings, from largest to smallest p Paragraph br Line break hr Horizontal line strong Important/bold text b Bold text em Emphasized/italic text i Italic text u Underlined text mark Highlighted text small Smaller text del Deleted/strikethrough text sub Subscript sup Superscript 3. Links and images Tag What it does a Creates a link img Displays an image figure Groups an image/illustration figcaption Caption for a figure Example: href="https://example.com">Visit Example src="photo.jpg" alt="A beautiful photo" 4. Lists Tag What it does ul Unordered/bullet list ol Ordered/numbered list li List item dl Description list dt Description term dd Description/details
