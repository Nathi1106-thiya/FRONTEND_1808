Closing Tag/paired tags

A closing tag marks the end of an HTML element. It uses a forward slash / before the tag name. example: hltml,head,body,title,h1-h6,ul,ol,table,etc..

Self-Closing Tag/void tags

A self-closing tag does not need a separate closing tag because it cannot contain text or other elements. In HTML5, these are officially called void elements. You may also see the older form with /, such as
or , but the slash is not required in HTML5. example: br,hr,img,input,link,source,etc..
